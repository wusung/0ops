# M2.2：GitHub Actions Dispatch + Callback 全鏈路 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 backend → GHA dispatch 觸發、ops_token 簽發、HMAC callback 驗章、dedup、狀態機推進、及 GHA workflow 完整實作，達成一次 dispatch → callback success → 狀態轉移的端到端鏈路。

**Architecture:** 
- **Phase 1**：callback endpoint 功能完整性驗證與測試補強（HMAC 驗章、timestamp 窗口、dedup、狀態轉移）

- **Phase 3**：端到端驗收腳本與整合測試

**Tech Stack:** Go 1.25、GitHub Actions、Cloud Native Buildpacks、HMAC-SHA256、PostgreSQL dedup

)

t.Fatalf("expected signature validation to fail, got true")
}
}

func TestDeployCallbackSignatureValidationAcceptsValidSignature(t *testing.T) {

根據 `docs/features/build-pipeline-and-callback/spec.md § 4.2` 的規格，創建 `deploy/workflows/deploy-app.yml`：

```yaml
name: deploy-app

on:
  repository_dispatch:
    types: [deploy-app]

permissions:
  contents: write
  packages: write

env:
  RUN_ID: ${{ github.event.client_payload.run_id }}
  APP_SLUG: ${{ github.event.client_payload.app_slug }}
  TEAM_SLUG: ${{ github.event.client_payload.team_slug }}
  COMMIT_SHA: ${{ github.event.client_payload.commit_sha }}
  REF: ${{ github.event.client_payload.ref }}
  IMAGE_REF: ${{ github.event.client_payload.image_ref }}
  OPS_TOKEN: ${{ github.event.client_payload.ops_token }}
  CALLBACK_URL: ${{ github.event.client_payload.callback_url }}
  TRACE_ID: ${{ github.event.client_payload.trace_id }}

jobs:
  deploy:
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      # 1. Checkout target repo
      - name: Checkout target repo
        uses: actions/checkout@v4
        with:
          repository: ${{ github.event.client_payload.repo }}
          ref: ${{ env.REF }}
          token: ${{ secrets.GITHUB_APP_TOKEN }}
          path: target

      # 2. GHCR login
      - name: Login GHCR
        run: |
          echo "${OPS_TOKEN}" | docker login ghcr.io -u ops-bot --password-stdin

      # 3. Pack build
      - name: Pack build
        working-directory: target
        run: |
          pack build "${IMAGE_REF}" \
            --builder paketobuildpacks/builder-jammy-base \
            --path . \
            --publish \
            --cache-image "${IMAGE_REF}-cache" \
            --env "BP_OCI_SOURCE=${COMMIT_SHA}"

      # 4. Trivy scan
      - name: Trivy scan
        uses: aquasecurity/trivy-action@v0
        id: trivy
        with:
          image-ref: ${{ env.IMAGE_REF }}
          severity: HIGH,CRITICAL
          exit-code: '0'
          ignore-unfixed: 'true'
          format: json
          output: trivy-report.json

      - name: Parse Trivy results
        id: scan_summary
        run: |
          HIGH=$(jq '[.Results[]?.Vulnerabilities[]? | select(.Severity=="HIGH")] | length' trivy-report.json)
          CRITICAL=$(jq '[.Results[]?.Vulnerabilities[]? | select(.Severity=="CRITICAL")] | length' trivy-report.json)
          echo "high=$HIGH" >> $GITHUB_OUTPUT
          echo "critical=$CRITICAL" >> $GITHUB_OUTPUT

      # 5. Render & push gitops
      - name: Checkout 0ops repo (for scripts)
        uses: actions/checkout@v4
        with:
          path: ops

      - name: Render & commit gitops
        run: ./ops/deploy/workflows/scripts/render-and-push-gitops.sh
        env:
          GITOPS_DEPLOY_KEY: ${{ secrets.GITOPS_DEPLOY_KEY }}

      # 6. Callback backend
      - name: Callback backend
        if: always()
        env:
          STATUS: ${{ job.status }}
          HIGH: ${{ steps.scan_summary.outputs.high }}
          CRITICAL: ${{ steps.scan_summary.outputs.critical }}
        run: |
          PAYLOAD=$(jq -nc \
            --arg run_id "$RUN_ID" \
            --arg status "$STATUS" \
            --arg trace_id "$TRACE_ID" \
            --arg image "$IMAGE_REF" \
            --argjson high "${HIGH:-0}" \
            --argjson critical "${CRITICAL:-0}" \
            '{run_id:$run_id, status:$status, trace_id:$trace_id, image:$image,
              scan_summary:{high:$high, critical:$critical}}')
          TS=$(date +%s)
          SIG=$(printf '%s' "${TS}.${PAYLOAD}" | openssl dgst -sha256 -hmac "$OPS_TOKEN" -hex | awk '{print $2}')
          curl -fsS -X POST "$CALLBACK_URL" \
            -H "Content-Type: application/json" \
            -H "X-0ops-Timestamp: $TS" \
            -H "X-0ops-Signature: sha256=$SIG" \
            --data "$PAYLOAD"
```

### Task 7: 創建 render-and-push-gitops.sh Script

**Files:**
- Create: `deploy/workflows/scripts/render-and-push-gitops.sh`

- [ ] **Step 1: 寫 script skeleton**

根據 spec，此 script 負責：
1. 用 `client_payload` 環境變數 render Kustomization YAML
2. 提交到 0ops-gitops repo 主分支
3. 重試 + rebase 最多 5 次

```bash
#!/usr/bin/env bash
set -euo pipefail

# render-and-push-gitops.sh
# Renders kustomization manifests and pushes to 0ops-gitops repo
# Expects environment variables:
#   - TEAM_SLUG, APP_SLUG, COMMIT_SHA, IMAGE_REF
#   - GITOPS_DEPLOY_KEY (SSH private key)
#   - GITOPS_REPO (optional, defaults to 0ops-gitops)

GITOPS_REPO="${GITOPS_REPO:-0ops-gitops}"
GITOPS_URL="${GITOPS_URL:-git@github.com:winshare/${GITOPS_REPO}.git}"
RETRY_MAX=5
RETRY_COUNT=0

# Setup SSH key
mkdir -p ~/.ssh
echo "$GITOPS_DEPLOY_KEY" > ~/.ssh/gitops_key
chmod 600 ~/.ssh/gitops_key
ssh-keyscan -t rsa github.com >> ~/.ssh/known_hosts 2>/dev/null

# Clone gitops repo
git clone -b main --depth 1 "$GITOPS_URL" gitops-repo || {
echo "Failed to clone gitops repo"
exit 1
}
cd gitops-repo

# Render manifests (placeholder)
mkdir -p "apps/${TEAM_SLUG}/${APP_SLUG}"
cat > "apps/${TEAM_SLUG}/${APP_SLUG}/kustomization.yaml" <<-KUSTOMIZATION
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization

images:
  - name: app
    newName: ${IMAGE_REF}

namespace: team-${TEAM_SLUG}
KUSTOMIZATION

# Commit & push with retry + rebase
git config user.email "ops@0ops.local"
git config user.name "0ops-bot"
git add "apps/${TEAM_SLUG}/${APP_SLUG}"

while [ $RETRY_COUNT -lt $RETRY_MAX ]; do
if git commit -m "Deploy ${TEAM_SLUG}/${APP_SLUG}:${COMMIT_SHA}"; then
if GIT_SSH_COMMAND="ssh -i ~/.ssh/gitops_key" git push origin main; then
echo "Pushed to gitops repo"
exit 0
fi
# Push conflict: rebase
GIT_SSH_COMMAND="ssh -i ~/.ssh/gitops_key" git pull --rebase origin main || true
fi
RETRY_COUNT=$((RETRY_COUNT + 1))
done

echo "Failed to push gitops after $RETRY_MAX retries"
exit 1
```
