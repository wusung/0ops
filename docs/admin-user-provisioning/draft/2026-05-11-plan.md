# Admin User Provisioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 實作 production 一次性 owner bootstrap 與 team 成員 invite/list/remove（管理者流程），並納入 preview/confirm、RBAC、audit、CLI、MCP contract。

**Architecture:** 沿用既有 `internal/server/auth` middleware 與 `preview` gate，新增 `members` 與 `admin bootstrap` handler/service，寫入統一 `audit_log`。CLI 與 MCP 只走 backend API，不直接碰 DB。所有 team-scoped 端點保持 `404 team_not_found` anti-enumeration。

**Tech Stack:** Go (chi/cobra), Postgres (goose/sqlc/pgx), MCP Go SDK, `testing` + `httptest`.
