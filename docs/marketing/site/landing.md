## capabilities

### capability
zh_title: 天生安全的重試
zh_body: 叫 agent 做兩次，只會發生一次。推 image、綁網域這種收不回的動作，絕不重複觸發——安全強制在平台後端，不是一句提醒。
en_title: Safe retries by design
en_body: Tell your agent twice, it happens once. Irreversible actions like pushing an image or binding a domain never fire twice — enforced in the platform, not a reminder an AI can skip.

### capability
zh_title: 改不了的紀錄
zh_body: 誰、什麼時候、對哪個 app 做了什麼，一清二楚。你隨時能匯出，並證明它從頭到尾沒被動過手腳——連我們也動不了。
en_title: A record no one can quietly edit
en_body: Who did what, to which app, and when — all there. Export it any time and prove it was never tampered with, not even by us.

### capability
zh_title: 為 agent 設計的介面

en_title: An interface built for agents
en_body: Your agent calls it directly — no buttons, no human in the loop. Others assume a human clicking; 0ops assumes an agent is driving.
