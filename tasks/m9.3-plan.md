## Components (TDD per component)

### A. `internal/server/security` (pure, no DB/side-effects)
- `risk.go` — `RiskLevel(action, args)` whitelist catalog (spec §5.1) + `RequiredPhrase(action, args)`.
- `policy.go` — `ResolvePATTTLDays` / `ResolveDeviceTTLDays` = min(req, teamCap, globalMax); only tightens (§7).
- `anomaly.go` — `EvaluateAnomaly(signals)` + `AbuseDetectedAction` const + reaction policy (v1 alert-only, no goroutine) (§6).
- `*_test.go` for all three.

### B. Migration `00015_preview_risk_level.sql`
- ADD COLUMN `risk_level text`, `required_phrase text` to `preview` (nullable; no NOT NULL DEFAULT one-shot).
- Down drops both. App-layer chokepoint sets them; reads COALESCE.

### C. db layer (`db/members.go`)
- `Preview` struct: + `RiskLevel`, `RequiredPhrase`.
- `CreatePreview`: compute via `security.RiskLevel`/`RequiredPhrase` from (action, args); store + return.
- `GetPreview`: SELECT with `COALESCE(risk_level,'normal')`, `COALESCE(required_phrase,'')`.
- DB integration test (gated): delete_app→critical+phrase; create_app→normal+"".

### D. DTO
- `PreviewResponse`: + `risk_level`, `required_phrase` (omitempty; absent = normal).
- `ConfirmDeleteAppRequest`: + `confirmation_phrase`.

### E. deleteapp service (the wired high-risk action)
- `ErrConfirmationPhraseMismatch`.
- `Confirm(... confirmationPhrase string)`: after action/team/actor match, if `preview.RiskLevel != normal` require `confirmationPhrase == preview.RequiredPhrase` (AND with preview_id; checked before consumed/expired so replay also requires it). Mismatch/empty → ErrConfirmationPhraseMismatch.
- service_test: phrase enforced; AND with preview_id (correct phrase + bad/expired preview still rejected; correct preview + bad phrase rejected); normal-risk unaffected.

### F. handlers (`delete_handlers.go`, `apps.go` writePreviewResponse)
- `deleteAppHandler`: read `req.ConfirmationPhrase`, pass to Confirm.
- `previewDeleteAppHandler`: set RiskLevel + RequiredPhrase in DTO.
- `writePreviewResponse`: set RiskLevel (from preview) so create_app shows normal.
- `writeDeleteAppError`: map ErrConfirmationPhraseMismatch → 400 `confirmation_phrase_mismatch`.
- delete_handlers_test: missing/wrong phrase → 400; correct → 200; preview shows risk_level=critical.

### G. CLI (`cli/root.go`)
- After preview, if `preview.RequiredPhrase != ""`, prompt for it; abort locally on mismatch; send in confirm request.

### H. MCP (`mcp/server/server.go`)
- `deleteAppInput`: + `confirmation_phrase`; pass through. Tool descriptions note the high-risk typed-confirmation + RISK header.
